Life Counter: Timer Style

How should the turn timer work on mobile?

A

Full Chess Clock

Set total game time in setup, split per player. Active player's clock ticks down. Pass turn to advance. Time-out = elimination. Just like the web version.

B

Simple Turn Timer

Shows elapsed time per turn and total game time. No countdown, no time pressure. Just informational.

C

Optional Chess Clock

Chess clock is available but can be toggled off in setup for casual games where you just want life tracking without time pressure.
