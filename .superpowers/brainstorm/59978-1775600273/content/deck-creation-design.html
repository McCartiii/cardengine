Deck creation — what should the flow look like?

Right now the deck editor loads immediately as "Untitled Deck" with no setup step. Which creation flow feels right?

A

Creation modal before entering the editor

Clicking "New Deck" opens a focused modal: enter a name, pick a format, optionally add a commander search. Confirm → drop into the full editor. Clean separation between "creating" and "building."

Inline header setup in the editor

The editor opens immediately, but the deck name is a big editable field at the top, with format chips right below it. Everything is inline — click the name to rename, click a format chip to change. Less ceremony, more direct.

Decks list page → creation card

The /decks landing page shows all your saved decks as cards. A prominent "New Deck" card is first in the grid. Clicking it opens a compact creation sheet (name + format). Your decks are browseable before you dive into one.
